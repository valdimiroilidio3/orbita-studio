# Órbita Studio — repositório

Três peças, uma marca:

| Pasta | O que é |
|---|---|
| **`agents-office-main/`** | o escritório 3D: seis salas, 35 agentes e o Cérebro. `npm install && npm start` → http://localhost:4520 |
| **`orbita-studio-integrations/`** | a ponte autenticada para fora: leads OSM, email, WhatsApp, GitHub, Instagram, Vercel, Gemini, Supabase. `npm ci && npm start` → http://localhost:4530 (guia em `docs/INTEGRATIONS.md`) |
| **`view-image-mcp/`** | servidor MCP `view_image`: dá olhos aos agentes (qualquer URL pública, incluindo Google Drive) |

Cada pasta é um pacote npm independente. Guias: `agents-office-main/README.md`,
`agents-office-main/AI.md` (motores de IA), `agents-office-main/PESQUISA.md` (leads Google),
`orbita-studio-integrations/docs/INTEGRATIONS.md`, `view-image-mcp/README.md`.
